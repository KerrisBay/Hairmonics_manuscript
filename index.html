Causal structure

Model formulation

1. Latent childhood trauma metrics

For each subject \(i\), the joint distribution of their underlying exposure to abuse (\(c_{i,1}\)) and neglect (\(c_{i,2}\)) is drawn from a centered multivariate normal distribution capturing population variance and structural trait correlation:

\[ \begin{align*} \begin{bmatrix} c_{i,1} \\ c_{i,2} \end{bmatrix} &\sim \text{Multivariate-Normal} \left( \begin{bmatrix} 0 \\ 0 \end{bmatrix}, \; \boldsymbol{\Sigma}_c \right) \\ \boldsymbol{\Sigma}_c &= \text{diag}(\boldsymbol{\sigma}_c) \, \boldsymbol{\Omega}_c \, \text{diag}(\boldsymbol{\sigma}_c) \end{align*} \]

Where \(\boldsymbol{\sigma}_c = [\sigma_{\text{abuse}}, \sigma_{\text{neglect}}]^T\) maps the population scales, and \(\boldsymbol{\Omega}_c\) represents the trait correlation matrix.

2. CTQ measurement (emission) layer

The individual’s true latent trauma states directly manifest across the five observed subscales of the Childhood Trauma Questionnaire. The Abuse factor (\(c_{i,1}\)) drives emotional, physical, and sexual dimensions, while the Neglect factor (\(c_{i,2}\)) drives emotional and physical neglect indicators:

\[ \begin{align*} y_{m}^{(\mathrm{EA})} &\sim \text{Normal}\left(\alpha_{\mathrm{EA}} + c_{\text{subj}[m], 1}, \; \sigma_{\mathrm{EA}}\right) \quad \text{[Emotional Abuse]} \\ y_{m}^{(\mathrm{PA})} &\sim \text{Normal}\left(\alpha_{\mathrm{PA}} + c_{\text{subj}[m], 1}, \; \sigma_{\mathrm{PA}}\right) \quad \text{[Physical Abuse]} \\ y_{m}^{(\mathrm{SA})} &\sim \text{Normal}\left(\alpha_{\mathrm{SA}} + c_{\text{subj}[m], 1}, \; \sigma_{\mathrm{SA}}\right) \quad \text{[Sexual Abuse]} \\ y_{m}^{(\mathrm{EN})} &\sim \text{Normal}\left(\alpha_{\mathrm{EN}} + c_{\text{subj}[m], 2}, \; \sigma_{\mathrm{EN}}\right) \quad \text{[Emotional Neglect]} \\ y_{m}^{(\mathrm{PN})} &\sim \text{Normal}\left(\alpha_{\mathrm{PN}} + c_{\text{subj}[m], 2}, \; \sigma_{\mathrm{PN}}\right) \quad \text{[Physical Neglect]} \end{align*} \]

3. Latent dynamics

The latent dysregulation state \(z_i(t)\) transitions over irregular time intervals (\(\Delta t = t - t'\)) according to a continuous-time (Ornstein–Uhlenbeck) engine. The individual recovery speed \(\lambda_i\) forces a strict positive bound via the structural baseline floor \(\lambda_0\):

\[ \begin{align*} z_i(t) \mid z_i(t') &\sim \text{Normal} \left(e^{-\lambda_i \Delta t} \, z_i(t'),\; \sigma_z \sqrt{1-e^{-2\lambda_i \Delta t}} \right) \\ \lambda_i &= \lambda_0 + \exp\left(\gamma_{\text{abuse}} \, c_{i,1} + \gamma_{\text{neglect}} \, c_{i,2}\right) \end{align*} \]

4. Longitudinal process state

The state trajectory begins at a unique initial tracking baseline anchored to a matched-pair intercept (\(u_{\text{pair}}\)) and shifted by diagnostic status (SSD):

\[ \begin{align*} z_i(t_0) &\sim \text{Normal}\left(u_{\text{pair}[i]} + \beta_{\mathrm{SSD}} \, \mathrm{SSD}_i, \; 1\right) \\ u_j &\sim \text{Normal}(0, \sigma_{\mathrm{pair}}) \end{align*} \]

The evolving state \(z_i(t)\) projects concurrent signals down into both historical biological archives and acute clinical cross-sections:

\[ \begin{align*} y_m^{(\mathrm{HCC})} &\sim \text{Student-t}\left(\nu = 6, \; a_{\mathrm{HCC}} + b_{\mathrm{HCC}}\, z_{\text{state}[m]}, \; \sigma_{\mathrm{HCC}}\right) \\ y_m^{(\mathrm{PANSS})} &\sim \text{Normal}\left(a_{\mathrm{PANSS}} + b_{\mathrm{PANSS}} \, z_{\text{state}[m]}, \; \sigma_{\mathrm{PANSS}}\right) \\ y_m^{(\mathrm{PSS})} &\sim \text{Normal}\left(a_{\mathrm{PSS}} + b_{\mathrm{PSS}} \, z_{\text{state}[m]}, \; \sigma_{\mathrm{PSS}}\right) \end{align*} \]

5. Prior distributions

\[ \begin{align*} \lambda_0, \, \gamma_{\text{abuse}}, \, \gamma_{\text{neglect}}, \, \beta_{\mathrm{SSD}} &\sim \text{Normal}(0, 1) \\ \alpha_{\mathrm{EA}}, \, \alpha_{\mathrm{PA}}, \, \alpha_{\mathrm{SA}}, \, \alpha_{\mathrm{EN}}, \, \alpha_{\mathrm{PN}} &\sim \text{Normal}(0, 1) \\ a_{\mathrm{PANSS}}, \, a_{\mathrm{PSS}}, \, a_{\mathrm{HCC}} &\sim \text{Normal}(0, 0.5) \\ b_{\mathrm{PANSS}}, \, b_{\mathrm{PSS}}, \, b_{\mathrm{HCC}} &\sim \text{Normal}(0, 1) \\ \sigma_z, \, \sigma_{\mathrm{pair}}, \, \sigma_{\mathrm{HCC}}, \, \sigma_{\mathrm{PANSS}}, \, \sigma_{\mathrm{PSS}} &\sim \text{Exponential}(1) \\ \sigma_{\mathrm{EA}}, \, \sigma_{\mathrm{PA}}, \, \sigma_{\mathrm{SA}}, \, \sigma_{\mathrm{EN}}, \, \sigma_{\mathrm{PN}} &\sim \text{Exponential}(1) \\ \boldsymbol{\sigma}_c &\sim \text{Exponential}(1) \\ \boldsymbol{\Omega}_c &\sim \text{LKJ}(\eta = 2) \end{align*} \]

// Covariance matrix for CTQ latent factor c1 (abuse) and c2 (neglect)
matrix[2, N_subj] c;
c = diag_pre_multiply(sigma_c, L_c) * c_raw;

// latent subject-level factors c[1, ] and c[2, ]. Implicit Bayesian imputation. 
vector[N_subj] lambda_subj;

for (i in 1:N_subj) {
  lambda_subj[i] = lambda_0 + exp(gamma_abuse * c[1, i] + gamma_neglect * c[2, i]);
}

// dynamic latent process 
vector[N_state] z;
for (k in 1:N_state) {
    // first point in time aligned between patients and controls
    if (is_first[k] == 1) {
        z[k] = u_pair[pair_id[k]] + beta_scz * scz[k] + 1 * z_raw[k];
    // Ornstein-Uhlenbeck process (exponential return with stochastic volatility)
    } else {
        real dt = time[k] - time[k-1];
        real phi = exp(-lambda_subj[subj_id[k]] * dt);
        real sigma_dt = sigma_z * sqrt(1 - square(phi));
        z[k] = phi * z[k-1] + sigma_dt * z_raw[k];
    }
  } 


}

Latent trauma metric stratification

CTQ subscales exhibit high mutual inter-correlation due to shared response variance. Modeling observed subscale scores as independent predictors introduces multicollinearity and leads to overestimating trauma burden when multiple subscales are elevated simultaneously (analogous to multiple motion sensors triggering from a single event). To resolve this, we employed a Bayesian implicit latent variable framework, modeling five observed CTQ subscale indicators (\(\mathbf{y}_{\text{EA}}, \mathbf{y}_{\text{PA}}, \mathbf{y}_{\text{SA}}, \mathbf{y}_{\text{EN}}, \mathbf{y}_{\text{PN}}\)) as expressions of two correlated latent factors: Abuse (\(c_{1}\)) and Neglect (\(c_{2}\)).

Mean latent factor score (\(c_{1}, c_{2}\)) represents standardized, continuous latent trait category, by which the subjects were assigned into trauma severity tiers.

Low trauma:   \(\frac{1}{2}(c_{1} + c_{2})\) \(\le -0.75\)

Medium trauma:   \(-0.75 <\) \(\frac{1}{2}(c_{1} + c_{2})\) \(< 0.75\)

High trauma:   \(\frac{1}{2}(c_{1} + c_{2})\) \(\ge 0.75\)

Because \(c_{1,i}\) and \(c_{2,i}\) are full posterior draws (not point estimates), each subject gets a posterior distribution over tiers rather than a single label.

Posterior predictive check of the latent metrics to the CTQ native scale could be displayed by converting the native CTQ using the following procedure:

  1. Taking a mean of the 3 abuse native subscales (EA, PA, SA).
  2. Taking a mean of the 2 neglect native subscales (EN, PN).
  3. Standardize each construct separately across subjects.
  4. Averaging the two z-scores.

#### Model formulation

##### 1. Latent childhood trauma metrics
For each subject $i$, the joint distribution of their underlying exposure to abuse ($c_{i,1}$) and neglect ($c_{i,2}$) is drawn from a centered multivariate normal distribution capturing population variance and structural trait correlation:

$$
\begin{align*}
\begin{bmatrix} c_{i,1} \\ c_{i,2} \end{bmatrix} &\sim \text{Multivariate-Normal} \left( \begin{bmatrix} 0 \\ 0 \end{bmatrix}, \; \boldsymbol{\Sigma}_c \right) \\
\boldsymbol{\Sigma}_c &= \text{diag}(\boldsymbol{\sigma}_c) \, \boldsymbol{\Omega}_c \, \text{diag}(\boldsymbol{\sigma}_c)
\end{align*}
$$

Where $\boldsymbol{\sigma}_c = [\sigma_{\text{abuse}}, \sigma_{\text{neglect}}]^T$ maps the population scales, and $\boldsymbol{\Omega}_c$ represents the trait correlation matrix.

##### 2. CTQ measurement (emission) layer
The individual's true latent trauma states directly manifest across the five observed subscales of the Childhood Trauma Questionnaire. The Abuse factor ($c_{i,1}$) drives emotional, physical, and sexual dimensions, while the Neglect factor ($c_{i,2}$) drives emotional and physical neglect indicators:

$$
\begin{align*}
y_{m}^{(\mathrm{EA})} &\sim \text{Normal}\left(\alpha_{\mathrm{EA}} + c_{\text{subj}[m], 1}, \; \sigma_{\mathrm{EA}}\right) \quad \text{[Emotional Abuse]} \\
y_{m}^{(\mathrm{PA})} &\sim \text{Normal}\left(\alpha_{\mathrm{PA}} + c_{\text{subj}[m], 1}, \; \sigma_{\mathrm{PA}}\right) \quad \text{[Physical Abuse]} \\
y_{m}^{(\mathrm{SA})} &\sim \text{Normal}\left(\alpha_{\mathrm{SA}} + c_{\text{subj}[m], 1}, \; \sigma_{\mathrm{SA}}\right) \quad \text{[Sexual Abuse]} \\
y_{m}^{(\mathrm{EN})} &\sim \text{Normal}\left(\alpha_{\mathrm{EN}} + c_{\text{subj}[m], 2}, \; \sigma_{\mathrm{EN}}\right) \quad \text{[Emotional Neglect]} \\
y_{m}^{(\mathrm{PN})} &\sim \text{Normal}\left(\alpha_{\mathrm{PN}} + c_{\text{subj}[m], 2}, \; \sigma_{\mathrm{PN}}\right) \quad \text{[Physical Neglect]}
\end{align*}
$$

##### 3. Latent dynamics 
The latent dysregulation state $z_i(t)$ transitions over irregular time intervals ($\Delta t = t - t'$) according to a continuous-time [(Ornstein–Uhlenbeck)](https://en.wikipedia.org/wiki/Ornstein%E2%80%93Uhlenbeck_process) engine. The individual recovery speed $\lambda_i$ forces a strict positive bound via the structural baseline floor $\lambda_0$:


$$
\begin{align*}
z_i(t) \mid z_i(t') &\sim \text{Normal} \left(e^{-\lambda_i \Delta t} \, z_i(t'),\; \sigma_z \sqrt{1-e^{-2\lambda_i \Delta t}} \right) \\
\lambda_i &= \lambda_0 + \exp\left(\gamma_{\text{abuse}} \, c_{i,1} + \gamma_{\text{neglect}} \, c_{i,2}\right)
\end{align*}
$$

##### 4. Longitudinal process state
The state trajectory begins at a unique initial tracking baseline anchored to a matched-pair intercept ($u_{\text{pair}}$) and shifted by diagnostic status (SSD):

$$
\begin{align*}
z_i(t_0) &\sim \text{Normal}\left(u_{\text{pair}[i]} + \beta_{\mathrm{SSD}} \, \mathrm{SSD}_i, \; 1\right) \\
u_j &\sim \text{Normal}(0, \sigma_{\mathrm{pair}})
\end{align*}
$$

The evolving state $z_i(t)$ projects concurrent signals down into both historical biological archives and acute clinical cross-sections:

$$
\begin{align*}
y_m^{(\mathrm{HCC})} &\sim \text{Student-t}\left(\nu = 6, \; a_{\mathrm{HCC}} + b_{\mathrm{HCC}}\, z_{\text{state}[m]}, \; \sigma_{\mathrm{HCC}}\right) \\
y_m^{(\mathrm{PANSS})} &\sim \text{Normal}\left(a_{\mathrm{PANSS}} + b_{\mathrm{PANSS}} \, z_{\text{state}[m]}, \; \sigma_{\mathrm{PANSS}}\right) \\
y_m^{(\mathrm{PSS})} &\sim \text{Normal}\left(a_{\mathrm{PSS}} + b_{\mathrm{PSS}} \, z_{\text{state}[m]}, \; \sigma_{\mathrm{PSS}}\right)
\end{align*}
$$

##### 5. Prior distributions

$$
\begin{align*}
\lambda_0, \, \gamma_{\text{abuse}}, \, \gamma_{\text{neglect}}, \, \beta_{\mathrm{SSD}} &\sim \text{Normal}(0, 1) \\
\alpha_{\mathrm{EA}}, \, \alpha_{\mathrm{PA}}, \, \alpha_{\mathrm{SA}}, \, \alpha_{\mathrm{EN}}, \, \alpha_{\mathrm{PN}} &\sim \text{Normal}(0, 1) \\
a_{\mathrm{PANSS}}, \, a_{\mathrm{PSS}}, \, a_{\mathrm{HCC}} &\sim \text{Normal}(0, 0.5) \\
b_{\mathrm{PANSS}}, \, b_{\mathrm{PSS}}, \, b_{\mathrm{HCC}} &\sim \text{Normal}(0, 1) \\
\sigma_z, \, \sigma_{\mathrm{pair}}, \, \sigma_{\mathrm{HCC}}, \, \sigma_{\mathrm{PANSS}}, \, \sigma_{\mathrm{PSS}} &\sim \text{Exponential}(1) \\
\sigma_{\mathrm{EA}}, \, \sigma_{\mathrm{PA}}, \, \sigma_{\mathrm{SA}}, \, \sigma_{\mathrm{EN}}, \, \sigma_{\mathrm{PN}} &\sim \text{Exponential}(1) \\
\boldsymbol{\sigma}_c &\sim \text{Exponential}(1) \\
\boldsymbol{\Omega}_c &\sim \text{LKJ}(\eta = 2)
\end{align*}
$$

CTQ subscales exhibit high mutual inter-correlation due to shared response variance. Modeling observed subscale scores as independent predictors introduces multicollinearity and leads to overestimating trauma burden when multiple subscales are elevated simultaneously (analogous to multiple motion sensors triggering from a single event). 
To resolve this, we employed a Bayesian implicit latent variable framework, modeling five observed CTQ subscale indicators ($\mathbf{y}_{\text{EA}}, \mathbf{y}_{\text{PA}}, \mathbf{y}_{\text{SA}}, \mathbf{y}_{\text{EN}}, \mathbf{y}_{\text{PN}}$) as expressions of two correlated latent factors: Abuse ($c_{1}$) and Neglect ($c_{2}$).



Mean latent factor score ($c_{1}, c_{2}$) represents standardized, continuous latent trait category, by which the subjects were assigned into trauma severity tiers.

Low trauma: &emsp; $\frac{1}{2}(c_{1} + c_{2})$ $\le -0.75$

Medium trauma: &emsp; $-0.75 <$ $\frac{1}{2}(c_{1} + c_{2})$ $< 0.75$

High trauma: &emsp; $\frac{1}{2}(c_{1} + c_{2})$ $\ge 0.75$

Because $c_{1,i}$ and $c_{2,i}$ are full posterior draws (not point estimates), each subject gets a posterior distribution over tiers rather than a single label.

```{stan scz_prior, output.var="scz_model_prior", cache=FALSE}
real <lower=0> lambda_0;
real gamma_abuse;
real gamma_neglect;
real <lower=0> sigma_z;
real <lower=0> sigma_pair;

real beta_scz;

real a_hcc;
real <lower=0> b_hcc;
real <lower=0> sigma_hcc;

real b_panss;

real <lower=0> sigma_pn;

real alpha_pa;
real alpha_sa;
real alpha_en;
real alpha_pn;

matrix[2, N_subj] c_raw;
vector <lower=0> [2] sigma_c;
cholesky_factor_corr[2] L_c;

}

transformed parameters {

// Covariance matrix for CTQ latent factor c1 (abuse) and c2 (neglect)
matrix[2, N_subj] c;
c = diag_pre_multiply(sigma_c, L_c) * c_raw;

// latent subject-level factors c[1, ] and c[2, ]. Implicit Bayesian imputation. 
vector[N_subj] lambda_subj;

for (i in 1:N_subj) {
  lambda_subj[i] = lambda_0 + exp(gamma_abuse * c[1, i] + gamma_neglect * c[2, i]);
}

// dynamic latent process 
vector[N_state] z;
for (k in 1:N_state) {
    // first point in time aligned between patients and controls
    if (is_first[k] == 1) {
        z[k] = u_pair[pair_id[k]] + beta_scz * scz[k] + 1 * z_raw[k];
    // Ornstein-Uhlenbeck process (exponential return with stochastic volatility)
    } else {
        real dt = time[k] - time[k-1];
        real phi = exp(-lambda_subj[subj_id[k]] * dt);
        real sigma_dt = sigma_z * sqrt(1 - square(phi));
        z[k] = phi * z[k-1] + sigma_dt * z_raw[k];
    }
  } 


}
```

```{r}
ppc_statistics <- function(rep_data, observed) {

  rep_stats <- rep_data |>
    group_by(.draw) |>
    summarise(
      mean = mean(y_rep),
      sd = sd(y_rep),
      q05 = quantile(y_rep, .05),
      median = median(y_rep),
      q95 = quantile(y_rep, .95),
      min = min(y_rep),
      max = max(y_rep),
      .groups = "drop"
    )

  obs_stats <- observed |>
    summarise(
      mean = mean(y),
      sd = sd(y),
      q05 = quantile(y, .05),
      median = median(y),
      q95 = quantile(y, .95),
      min = min(y),
      max = max(y)
    ) |>
    pivot_longer(
      everything(),
      names_to = "statistic",
      values_to = "observed"
    )

  rep_stats |>
    pivot_longer(
      - .draw,
      names_to = "statistic",
      values_to = "replicated"
    ) |>
    left_join(obs_stats, by = "statistic")
}
```

```{r}
  rep_stats <- rep_data |>
    group_by(.draw) |>
    summarise(
      mean = mean(y_rep),
      sd = sd(y_rep),

    summarise(
      mean = mean(y),
      sd = sd(y),

    pivot_longer(

      names_to = "statistic",

    ) |>

}
```
